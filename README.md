# 悬空地形块

[English](README.en.md)

给《Timberborn》增加一种可以悬空铺设的地形块。外观、造价和科研与原版地形块相同，但不受“必须有下方支撑”的限制。海狸按普通工地施工，建成之后这一格变成真地形。

## 它做什么

- 在**地形改造**工具组里提供「悬空地形块」。
- 可以贴着崖壁向外延伸，也可以悬在空中，不必等后方或下方的地形块先完工。
- 建造消耗 **4 个泥土**，科研花费 **1000** 科学点，与原版地形块一致。
- 海狸把材料送到工地并建完后，方块会消失，原地留下一格真地形。
- 建成后的地形可以挖掘、挡水、种树，也可以在上面继续放置建筑。
- 还没建完的工地可以用拆除工具取消。用掉的泥土不会在建成时被退回来。

建成后的地形仍然遵守原版的支撑规则。炸药或挖掘拆掉支撑后，后面失去支撑的地形会一起塌落。

## 要求

- 游戏版本不低于 **1.1.0.0**
- 依赖 [Harmony](https://steamcommunity.com/workshop/filedetails/?id=3284904751) **2.4.1** 或更高版本
